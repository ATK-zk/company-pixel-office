# Company Pixel Office

Static pixel office for our trading team (8 people: David, Rex, Lyra, Kai, Finn, Jay, Quinn, Sage).
Layout/furniture like atk-zk/pixel-office; sprites & style from pixel-agents (MIT, see LICENSE-pixel-agents-MIT).
No settings / no editor. Status comes from `status.json` (static snapshot; edit and push to update).
Background music: CC0 medieval town loops, see MUSIC_CREDITS.md. Toggle with the 🔇/🎵 button.

Live: https://atk-zk.github.io/company-pixel-office/
